
# Week 2 – Network Discovery and Nmap 🔍

## Overview
During Week 2 of my Cybersecurity Internship at NetworkWalks, I explored basic networking concepts and practised network discovery using Nmap and Zenmap on Windows.

## Topics Covered
- Understanding IP addresses and subnet masks.
- Checking network configuration using the ipconfig command.
- Understanding IPv4 addresses and default gateways.
- Introduction to Nmap and Zenmap.
- Performing local network discovery.
- Identifying active hosts in a network.
- Understanding IP addresses and MAC addresses.

## Practical Tasks

### 1. Checking Network Configuration
Used the Windows CMD command:

```cmd
ipconfig
```

Learned how to identify:
- IPv4 Address
- Subnet Mask
- Default Gateway

### 2. Network Scanning Using Zenmap

Used Zenmap, the graphical interface of Nmap, to perform a Ping Scan.

Command used:

```bash
nmap -sn 192.168.0.0/24
```

### 3. Network Discovery Results

- Scanned a local network containing 256 IP addresses.
- Identified 2 hosts responding to the scan.
- Observed host status and MAC address information.
- Understood how Nmap performs host discovery.

## Tools Used
- Windows Command Prompt (CMD)
- Nmap
- Zenmap

## Learning Outcomes
- Learned how to check IP configuration in Windows.
- Understood basic network addressing.
- Gained practical experience with Nmap.
- Learned how to discover active devices on a local network.
- Understood the basic difference between IP and MAC addresses.

## Conclusion
This week helped me understand basic networking and gain hands-on experience with network discovery using Nmap and Zenmap.

More practical work and learning experiences will be documented in the upcoming weeks.
